# Learning Objectives

By the end of this lesson the student should be able to:

- Greet someone.
- Ask how someone is.
- Introduce themselves.
- Ask someone's name.
- Say where they are from.
- End a simple conversation politely.

---

# Allowed Vocabulary

## Greetings

- Hola
- Buenos días
- Buenas tardes
- Adiós
- Hasta luego

## Responses

- Bien
- Muy bien
- Más o menos

## Introductions

- Me llamo...
- Soy de...
- Mucho gusto.
- Encantado. (male)
- Encantada. (female)

## Questions

- ¿Qué tal?
- ¿Cómo estás?
- ¿Cómo te llamas?
- ¿De dónde eres?

## Countries

- Sudáfrica
- España
- México
- Argentina
- Chile

## Drinks

- café
- té
- chocolate

# Grammar

## Introducing yourself

```
Me llamo María.
```

Means:

> My name is María.

---

## Saying where you're from

```
Soy de Sudáfrica.
```

Pattern:

```
Soy de <country>.
```

---

## Asking someone's name

```
¿Cómo te llamas?
```

---

## Asking where someone is from

```
¿De dónde eres?
```

# Culture

Spain:

- People commonly greet with one kiss on each cheek.

Latin America:

- Friends often greet with one kiss on the cheek or a hug.

Discussion question:

> ¿Qué prefieres?

Possible answers:

- Besos en la mejilla.
- Abrazos.
- Un apretón de manos.

# Constraints for the Tutor

The tutor should:

- Primarily use vocabulary from this lesson.
- Prefer short sentences.
- Avoid introducing new grammar unless required.
- If new vocabulary is unavoidable, immediately explain it.
- Correct mistakes gently.
- Ask one question at a time.
- Keep conversations realistic.
- Encourage the student to answer in Spanish.
- Gradually remove English as confidence improves.
